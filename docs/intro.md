# 欢迎使用 Welight

**Welight** 是一个轻量化的公众号文章排版美化应用。

## 产品定位

Welight 是一个 **轻量化**的公众号文章排版美化应用，就这么简单。

## 关于 Welight

Welight的前身是一个名为 0703 的公众号文章排版网页。这是我在做了几年公众号、前前后后体验了几乎市面上所有的公众号排版产品之后，决定自己开发的一个轻量化的公众号排版工具。

这个工具最初的定义就是一个自用的网页版本的公众号排版应用，没想过商业化，没想过任何推广。以至于当我写完代码，功能可用之时才发现原来连一个名称都没想好，索性看了一样那天的日期，于是 0703 就这样随性的诞生了。

闲来无事，打算把 0703 录了个视频，放到了哔哩哔哩。没想到收到了很多网友的好评和反馈，也正是这些反馈和支持，我们陆陆续续对0703维护和更新了一段时间，再后来，0703 的桌面端开发完成，正式命名为 Welight，从发布以来，依旧一直免费开放下载和使用。

## 快速开始

让我们开始 **Welight 之旅**，只需要 **5 分钟**。

### 你需要什么

- 一台支持 Linux/Mac/Windows 系统的电脑，系统版本不要太旧。
- 会上网、能打开指定的下载官网；
- 会基本的安装包程序安装；


### 下载 Welight

你可以从以下渠道下载 Welight：

- [官方网站](https://waer.ltd)

### 开始使用

1. 打开 Welight 应用
2. 在编辑区编辑你的公众号文章内容
3. 选择你喜欢的主题
4. 点击一键复制
5. 粘贴到公众号编辑器

就是这么简单！

## 主要特性

- **丰富的主题** - 多种精美主题可选
- **实时预览** - 所见即所得的编辑体验
- **一键复制** - 快速复制到公众号编辑器
- **Markdown 支持** - 支持 Markdown 语法
- **AI 转换** - 智能转换普通文本为 Markdown
- **规范检查** - 自动检查内容是否符合排版限制规范
- **图片云存储** - 支持自己配置云存储，快捷插入图片，省去公众号编辑器再次配图的繁琐。
