# 基本使用

## 如果你会 Markdown 语法

1. 打开 Welight，在编辑区编辑你的公众号文章内容
2. 你的编辑区的编辑结果会在右侧的预览区中实时同步渲染显示
3. 内容编辑完成后，建议点一下编辑区右上角的 **规范检查**，扫一遍
4. 在预览区顶部选择你喜欢的主题
5. 点击顶部菜单栏中的 **一键复制**按钮
6. 打开公众号编辑器，将复制的内容粘贴到编辑器中
7. 结束

## 如果你不会 Markdown 语法

不用担心，Welight 编辑区中提供了斜杠快捷指令和划词功能。

### 斜杠快捷指令

你可以在编辑区中通过输入"/"命令，唤出快捷面板，面板中涵盖了很多常用的 Markdown 语法。

你需要做的就是选择需要的语法，它会自动在编辑区中创建对应的语法格式，就是这么简单。

![斜杠快捷指令](https://images.waer.ltd/notes/202509271159013.png)

### 划词功能

类似的快捷语法功能在划词功能中也提供了，选中你要调整的内容，比如想实现某个关键词的加粗效果，那么你可以选中这个关键词，在划词菜单中选择对应的语法，编辑器会将这选中的内容进行加粗处理。

![划词功能](https://images.waer.ltd/notes/202509271202495.png)

### AI 转换功能

如果你还是觉得这样不够方便，那么你可以选择使用 AI 转换功能：

1. 编辑好你的文章内容，使用普通的 txt 文本格式
2. 选择顶部菜单中的 **转换**功能
3. 可以一键自动将 txt 格式的内容智能转为 **Markdown** 语法格式

如果要转换的内容很长，可以选中一部分内容，在划词菜单中选择转换。

## 常用快捷键

- `Ctrl/Cmd + S`：保存文档
- `Ctrl/Cmd + C`：复制选中内容
- `Ctrl/Cmd + V`：粘贴内容
- `Ctrl/Cmd + Z`：撤销操作
- `Ctrl/Cmd + Y`：重做操作
