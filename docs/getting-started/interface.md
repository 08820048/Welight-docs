# 界面结构介绍

Welight 整体采用左右结构+侧边栏的组合方式作为默认界面布局。

![界面布局](https://images.waer.ltd/notes/202509271130194.png)

## 布局模式

### 分屏模式（默认）

当 **主题编辑**被展开的情况下，结构是左右布局：
- **左侧**：显示实时的编辑结果
- **右侧**：作为主题编辑器功能的主要区域

![主题编辑模式](https://images.waer.ltd/notes/202509271134328.png)

### 其他布局模式

应用同时支持多种布局模式的切换，用户可以根据自己的需求和喜好进行布局切换：

- **全屏编辑**：专注于内容编辑
- **全屏预览**：专注于预览效果
- **分屏模式**：同时查看编辑和预览（默认模式）

## 主要区域

### 编辑区
- 支持 Markdown 语法
- 提供斜杠快捷指令
- 支持划词功能
- 实时语法高亮

### 预览区
- 实时渲染编辑结果
- 主题选择器
- 一键复制功能

### 工具栏
- 文件操作
- 主题管理
- 转换功能
- 规范检查
- AI 服务
