# AI 服务介绍

Welight 集成了强大的 AI 服务，帮助你更高效地创作和编辑内容。

## AI 转换功能

### 文本转 Markdown

AI 转换功能可以智能地将普通文本转换为 Markdown 格式：

- **自动识别标题**：根据内容结构自动添加标题标记
- **段落优化**：智能分段和格式化
- **列表识别**：自动识别并转换列表格式
- **强调标记**：识别重点内容并添加强调标记

### 使用方法

1. **全文转换**：
   - 在编辑区输入普通文本
   - 点击顶部菜单的"转换"按钮
   - AI 会自动分析并转换整篇文章

2. **选择转换**：
   - 选中需要转换的文本片段
   - 在划词菜单中选择"转换"
   - 只转换选中的部分内容

### 转换效果

转换前：
```
这是一个标题
这是正文内容，包含一些重要信息。
1. 第一点
2. 第二点
3. 第三点
```

转换后：
```markdown
# 这是一个标题

这是正文内容，包含一些**重要信息**。

1. 第一点
2. 第二点  
3. 第三点
```

## AI 内容优化

### 语言润色

AI 可以帮助优化你的文章内容：

- **语法检查**：自动检测并修正语法错误
- **表达优化**：提升文章的表达效果
- **风格统一**：保持文章风格的一致性
- **可读性提升**：优化句式和段落结构

### 内容扩展

- **要点展开**：将简短的要点扩展为完整段落
- **案例补充**：为观点添加相关案例
- **逻辑完善**：补充逻辑链条，使文章更连贯

## AI 辅助写作

### 标题生成

根据文章内容，AI 可以：

- 生成吸引人的标题
- 提供多个标题选项
- 优化现有标题

### 摘要生成

- 自动生成文章摘要
- 提取关键信息
- 控制摘要长度

### 标签推荐

- 根据内容推荐相关标签
- 提高文章的可发现性
- 便于内容分类管理

## 使用建议

### 最佳实践

1. **先写后转**：建议先完成内容创作，再使用 AI 转换
2. **分段处理**：对于长文章，建议分段使用 AI 功能
3. **人工校对**：AI 转换后建议人工检查和调整
4. **保存原文**：转换前建议保存原始文本

### 注意事项

- AI 转换结果可能需要微调
- 复杂格式可能需要手动调整
- 建议结合人工编辑使用
- 注意保护隐私信息
