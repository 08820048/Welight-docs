# 规范检查

Welight 内置了智能的规范检查功能，帮助你创作更规范、更专业的内容。

## 功能概述

规范检查功能会自动扫描你的文章内容，检测可能存在的问题并提供修改建议。

### 检查项目

#### 格式规范

- **标题层级**：检查标题的层级结构是否合理
- **段落间距**：检查段落间距是否适当
- **列表格式**：检查列表的格式是否正确
- **代码块**：检查代码块的语法标记

#### 内容质量

- **错别字检测**：识别常见的错别字
- **标点符号**：检查标点符号的使用
- **语法错误**：检测基本的语法问题
- **重复内容**：发现重复的句子或段落

#### 公众号规范

- **字数统计**：统计文章字数
- **阅读时长**：估算阅读时长
- **关键词密度**：分析关键词使用情况
- **图片标注**：检查图片是否有适当的说明

## 使用方法

### 自动检查

- 在编辑过程中实时检查
- 问题内容会有下划线标记
- 鼠标悬停查看具体问题

### 手动检查

1. 点击编辑区右上角的"规范检查"按钮
2. 系统会全面扫描文章内容
3. 在侧边栏显示检查结果
4. 点击问题项可跳转到对应位置

### 检查报告

检查完成后会生成详细报告：

- **问题总数**：发现的问题数量
- **问题分类**：按类型分组显示
- **严重程度**：标记问题的重要性
- **修改建议**：提供具体的修改建议

## 检查规则

### 标题规范

- **层级跳跃**：不建议从 H1 直接跳到 H3
- **标题长度**：标题不宜过长或过短
- **标题重复**：避免相同的标题
- **标题格式**：检查标题的格式是否统一

### 段落规范

- **段落长度**：单个段落不宜过长
- **空行使用**：检查空行的使用是否合理
- **首行缩进**：检查段落首行缩进
- **段落结构**：检查段落的逻辑结构

### 标点符号

- **中英文标点**：检查中英文标点的混用
- **标点位置**：检查标点符号的位置
- **引号配对**：检查引号是否配对
- **省略号格式**：检查省略号的格式

### 语言表达

- **口语化表达**：检测过于口语化的表达
- **重复用词**：发现重复使用的词汇
- **语句通顺**：检查语句是否通顺
- **逻辑连贯**：检查文章逻辑是否连贯

## 自定义规则

### 规则配置

你可以根据需要调整检查规则：

- **启用/禁用规则**：选择需要的检查项目
- **严格程度**：调整检查的严格程度
- **自定义词典**：添加专业术语词典
- **忽略列表**：设置需要忽略的内容

### 个人偏好

- **写作风格**：设置个人写作风格偏好
- **行业术语**：添加行业相关术语
- **常用词汇**：设置常用词汇白名单
- **格式模板**：保存常用的格式模板

## 修改建议

### 问题分级

- **错误**：必须修改的问题（红色标记）
- **警告**：建议修改的问题（黄色标记）
- **建议**：可选的优化建议（蓝色标记）

### 一键修复

对于一些简单的问题，系统提供一键修复功能：

- **标点符号**：自动修正标点符号
- **空格问题**：自动调整空格
- **格式统一**：统一相似的格式
- **错别字**：自动替换常见错别字

### 批量处理

- **批量接受**：一次性接受所有建议
- **分类处理**：按问题类型批量处理
- **选择性修复**：选择特定问题进行修复

## 使用技巧

### 最佳实践

1. **写作完成后检查**：建议在写作完成后进行全面检查
2. **分段检查**：对于长文章，可以分段进行检查
3. **重点关注错误**：优先处理标记为"错误"的问题
4. **保持个人风格**：不必完全按照建议修改

### 注意事项

- 检查结果仅供参考，最终决定权在作者
- 某些专业术语可能被误判，可添加到白名单
- 创意性表达可能不符合规范，但可以保留
- 定期更新检查规则以适应新的写作需求
