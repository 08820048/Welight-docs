# 云存储服务介绍

Welight 提供了便捷的云存储服务，让你的文档随时随地可访问。

## 功能特性

### 自动同步

- **实时同步**：编辑内容自动保存到云端
- **多设备同步**：在不同设备间无缝切换
- **版本控制**：保留文档的历史版本
- **冲突解决**：智能处理多设备编辑冲突

### 数据安全

- **加密存储**：所有数据采用加密存储
- **备份机制**：多重备份保障数据安全
- **访问控制**：严格的权限管理
- **隐私保护**：遵循数据保护法规

## 使用方法

### 账户注册

1. 点击右上角的"登录"按钮
2. 选择注册新账户
3. 填写必要信息
4. 验证邮箱或手机号
5. 完成注册

### 文档同步

#### 自动同步

- 编辑文档时自动保存到云端
- 无需手动操作
- 支持离线编辑，联网后自动同步

#### 手动同步

- 点击"同步"按钮强制同步
- 查看同步状态
- 解决同步冲突

### 文档管理

#### 文档列表

- 查看所有云端文档
- 按时间、名称排序
- 搜索特定文档

#### 文档操作

- **新建文档**：创建新的云端文档
- **删除文档**：删除不需要的文档
- **重命名**：修改文档名称
- **复制链接**：分享文档链接

## 存储空间

### 免费额度

- 新用户免费获得 100MB 存储空间
- 可存储约 1000 篇文章
- 支持基本的同步功能

### 付费升级

- **基础版**：1GB 存储空间
- **专业版**：10GB 存储空间
- **企业版**：100GB 存储空间
- 更多高级功能

## 数据导出

### 支持格式

- **Markdown**：原始 Markdown 格式
- **HTML**：网页格式
- **PDF**：便于打印和分享
- **Word**：Microsoft Word 格式

### 导出方法

1. 选择要导出的文档
2. 点击"导出"按钮
3. 选择导出格式
4. 下载到本地

## 常见问题

### 同步问题

**Q: 文档没有同步怎么办？**
A: 检查网络连接，尝试手动同步，或重启应用。

**Q: 出现同步冲突怎么处理？**
A: 系统会提示冲突，你可以选择保留哪个版本，或合并内容。

### 存储问题

**Q: 存储空间不够用怎么办？**
A: 可以删除不需要的文档，或升级到更大的存储套餐。

**Q: 如何查看存储使用情况？**
A: 在设置页面可以查看当前的存储使用情况。
