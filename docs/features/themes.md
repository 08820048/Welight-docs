# 主题系统

Welight 提供了丰富的主题系统，让你的文章排版更加美观和专业。

## 主题选择

在预览区顶部，你可以找到主题选择器，点击即可切换不同的主题风格。

### 内置主题

Welight 内置了多种精美主题：

- **默认主题**：简洁清爽的基础主题
- **商务主题**：适合商务场景的专业主题
- **文艺主题**：适合文艺内容的优雅主题
- **科技主题**：适合科技内容的现代主题
- **更多主题**：持续更新中...

### 主题特性

每个主题都包含：

- **字体样式**：标题、正文、代码的字体设置
- **颜色方案**：主色调、辅助色、背景色等
- **间距布局**：段落间距、行高、边距等
- **装饰元素**：分割线、引用框、代码块样式等

## 主题推荐系统

Welight 还提供了智能的主题推荐功能，根据你的内容类型和风格偏好，为你推荐最适合的主题。

### 推荐算法

系统会根据以下因素进行推荐：

- **内容类型**：技术文章、生活分享、商务报告等
- **文章长度**：短文、长文的不同排版需求
- **使用历史**：你的主题使用偏好
- **热门趋势**：当前流行的主题风格

### 个性化定制

你还可以：

- **收藏主题**：将喜欢的主题加入收藏夹
- **主题评分**：为使用过的主题打分
- **自定义标签**：为主题添加个人标签

## 主题预览

在选择主题时，你可以：

- **实时预览**：立即查看主题效果
- **对比模式**：同时预览多个主题
- **全屏预览**：全屏查看主题效果

## 主题更新

- 定期更新新主题
- 优化现有主题
- 根据用户反馈调整主题
