# 预览模式使用

Welight 提供了多种预览模式，让你能够从不同角度查看和检查你的文章效果。

## 预览模式类型

### 实时预览

**默认模式**，在编辑的同时实时查看渲染效果：

- **即时反馈**：编辑内容立即在预览区显示
- **同步滚动**：编辑区和预览区同步滚动
- **错误提示**：语法错误会实时标记
- **性能优化**：针对大文档优化渲染性能

### 全屏预览

专注于查看文章的最终效果：

- **沉浸式体验**：隐藏编辑界面，专注于内容
- **真实效果**：模拟公众号的真实显示效果
- **多种尺寸**：支持不同设备尺寸的预览
- **快捷切换**：快速在编辑和预览间切换

### 移动端预览

模拟移动设备上的显示效果：

- **响应式设计**：自适应不同屏幕尺寸
- **触摸交互**：模拟移动端的交互体验
- **字体调整**：针对移动端优化字体大小
- **加载速度**：模拟移动网络的加载效果

## 预览功能

### 主题切换

在预览模式下快速切换主题：

- **主题选择器**：在预览区顶部选择主题
- **实时切换**：立即查看不同主题的效果
- **对比模式**：同时预览多个主题效果
- **收藏主题**：收藏喜欢的主题便于快速切换

### 缩放功能

调整预览内容的显示比例：

- **自由缩放**：使用滚轮或手势缩放
- **预设比例**：50%、75%、100%、125%、150%
- **适应窗口**：自动调整到适合窗口的大小
- **原始尺寸**：查看内容的原始尺寸

### 导出预览

将预览内容导出为不同格式：

- **图片导出**：导出为 PNG、JPG 格式
- **PDF 导出**：生成 PDF 文件
- **HTML 导出**：导出为网页格式
- **打印预览**：查看打印效果

## 预览设置

### 显示选项

自定义预览区的显示内容：

- **显示标尺**：显示页面边距和尺寸标尺
- **显示网格**：显示对齐网格线
- **高亮链接**：高亮显示文章中的链接
- **显示目录**：在侧边显示文章目录

### 背景设置

调整预览区的背景：

- **纯色背景**：设置纯色背景
- **渐变背景**：使用渐变色背景
- **图片背景**：使用自定义图片作为背景
- **透明背景**：设置透明背景

### 字体设置

调整预览文字的显示：

- **字体大小**：调整全局字体大小
- **行间距**：调整行间距
- **字体族**：选择不同的字体
- **字重调整**：调整字体粗细

## 快捷操作

### 键盘快捷键

- `F11`：切换全屏预览
- `Ctrl/Cmd + +`：放大预览
- `Ctrl/Cmd + -`：缩小预览
- `Ctrl/Cmd + 0`：重置缩放比例
- `Ctrl/Cmd + P`：打印预览

### 鼠标操作

- **双击**：切换全屏预览
- **滚轮**：缩放预览内容
- **拖拽**：移动预览内容（缩放状态下）
- **右键菜单**：快速访问预览选项

## 预览优化

### 性能优化

针对大文档的预览优化：

- **懒加载**：按需加载内容
- **虚拟滚动**：优化长文档的滚动性能
- **缓存机制**：缓存渲染结果
- **异步渲染**：避免界面卡顿

### 兼容性

确保预览效果的准确性：

- **浏览器兼容**：兼容主流浏览器
- **平台一致**：不同平台显示一致
- **版本兼容**：兼容不同版本的公众号编辑器
- **字体回退**：处理字体不可用的情况

## 使用技巧

### 最佳实践

1. **定期预览**：在编辑过程中定期切换到预览模式
2. **多主题测试**：尝试不同主题查看效果
3. **移动端检查**：确保在移动端显示正常
4. **打印测试**：如需打印，提前查看打印效果

### 常见问题

**Q: 预览效果与实际发布效果不一致？**
A: 可能是平台差异导致，建议在目标平台进行最终确认。

**Q: 预览加载很慢？**
A: 可以尝试关闭一些高级预览功能，或者分段预览长文档。

**Q: 某些元素在预览中显示异常？**
A: 检查 Markdown 语法是否正确，或者尝试刷新预览。
