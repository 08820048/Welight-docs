# 划词功能

划词功能是 Welight 的一个强大特性，让你能够快速对选中的文本进行格式化和处理。

## 功能概述

当你在编辑区选中任何文本时，会自动弹出划词工具栏，提供各种快捷操作。

### 基本格式化

#### 文本样式

- **加粗**：将选中文本设置为粗体
- **斜体**：将选中文本设置为斜体
- **删除线**：为选中文本添加删除线
- **下划线**：为选中文本添加下划线
- **行内代码**：将选中文本标记为代码

#### 文本颜色

- **文字颜色**：设置文字的颜色
- **背景颜色**：设置文字的背景色
- **高亮标记**：添加高亮效果
- **预设配色**：使用预设的颜色方案

### 结构化操作

#### 标题转换

- **H1-H6**：将选中文本转换为不同级别的标题
- **智能识别**：根据内容自动判断合适的标题级别
- **批量转换**：同时转换多个标题

#### 列表操作

- **无序列表**：转换为无序列表项
- **有序列表**：转换为有序列表项
- **任务列表**：转换为可勾选的任务列表
- **嵌套列表**：创建多级嵌套列表

#### 引用和代码

- **引用块**：将选中内容转换为引用格式
- **代码块**：转换为代码块并可选择语言
- **表格**：将选中内容转换为表格格式
- **分割线**：在选中位置插入分割线

## 高级功能

### AI 增强

#### 智能转换

- **格式识别**：自动识别文本的格式意图
- **语法修正**：自动修正 Markdown 语法错误
- **内容优化**：优化文本的表达和结构
- **风格统一**：统一文档的写作风格

#### 内容处理

- **文本翻译**：将选中文本翻译为其他语言
- **内容摘要**：为长段落生成摘要
- **关键词提取**：提取文本中的关键词
- **情感分析**：分析文本的情感倾向

### 链接和媒体

#### 链接操作

- **创建链接**：为选中文本创建超链接
- **链接检查**：验证链接的有效性
- **链接预览**：预览链接的内容
- **批量链接**：批量处理多个链接

#### 媒体插入

- **插入图片**：在选中位置插入图片
- **图片描述**：为图片添加描述文字
- **视频嵌入**：嵌入视频链接
- **音频插入**：插入音频文件

## 自定义设置

### 工具栏配置

你可以自定义划词工具栏的内容：

- **功能选择**：选择需要显示的功能按钮
- **按钮排序**：调整按钮的显示顺序
- **分组设置**：将相关功能分组显示
- **快捷键绑定**：为常用功能设置快捷键

### 样式定制

- **工具栏主题**：选择工具栏的外观主题
- **按钮大小**：调整按钮的大小
- **显示动画**：设置工具栏的显示动画
- **透明度**：调整工具栏的透明度

### 行为设置

- **触发方式**：设置工具栏的触发条件
- **显示延迟**：设置工具栏出现的延迟时间
- **自动隐藏**：设置工具栏的自动隐藏时间
- **位置调整**：调整工具栏的显示位置

## 使用技巧

### 快速操作

#### 连续操作

- **多次点击**：连续点击可以切换不同的格式
- **组合使用**：可以同时应用多种格式
- **撤销重做**：支持撤销和重做操作
- **批量处理**：选中多段文本进行批量操作

#### 键盘配合

- **Shift + 选择**：扩展选择范围
- **Ctrl + 选择**：多选不连续的文本
- **双击选词**：快速选中单词
- **三击选段**：快速选中段落

### 最佳实践

1. **先选后操作**：先选中文本，再选择需要的格式
2. **预览效果**：操作后及时查看预览效果
3. **保持一致**：在同一文档中保持格式的一致性
4. **合理使用**：避免过度使用格式化功能

### 常见场景

#### 文章编辑

- **标题设置**：快速设置文章的标题层级
- **重点标记**：为重要内容添加强调格式
- **列表整理**：将散乱的内容整理为列表
- **引用添加**：为引用内容添加引用格式

#### 内容优化

- **格式统一**：统一相似内容的格式
- **错误修正**：快速修正格式错误
- **样式调整**：调整文本的视觉效果
- **结构优化**：优化文档的结构层次

## 故障排除

### 常见问题

**Q: 划词工具栏不显示？**
A: 检查是否正确选中了文本，或者尝试重新选择。

**Q: 某些功能按钮是灰色的？**
A: 可能是当前选中的内容不支持该功能，或者需要特定的上下文。

**Q: 格式化后效果不正确？**
A: 检查 Markdown 语法是否正确，或者尝试撤销后重新操作。

### 性能优化

- **选择范围**：避免选择过大的文本范围
- **功能精简**：关闭不常用的功能以提高性能
- **及时保存**：定期保存文档避免数据丢失
- **清理缓存**：定期清理应用缓存
